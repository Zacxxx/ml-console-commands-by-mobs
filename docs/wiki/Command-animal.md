# mobs.animal

Guide for **0.15.0-alpha.1**, game **0.8.117**.

Click inside an owned region to spawn 1..20 animals using native livestock registration; preview available.

```text
mobs.animal <type> [1..20] [preview]
```

## In-game advice

`mobs.advice.animal` or `mobs.advice animal`. These display help without executing the action.

## Target

Run the command, close the console, then click the intended location in an owned region. It is a one-shot tool with a five-minute expiry. mobs.cancel disarms it. Preview also requires the click, but changes nothing.

## Steps

Choose ox, horse, mule, sheep, lamb, goat, pig, chicken, hound, cow, calf, deer or hare; optionally 1..20 animals and preview.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.animal ox 1 preview
mobs.animal sheep 3
```

## Limits and expected results

These are individual native spawned animals. deer/hare here do NOT create a registered hunting resource node; a hunting icon/working herd is not implemented. Do not use item IDs. No undo.
