# mobs.speed

Guide for **0.16.1-alpha.5**, game **0.8.117**.

Read or request game speed through the native game function; 0 pauses and 1 resumes normally.

```text
mobs.speed [0..12]
```

## In-game advice

`mobs.advice.speed` or `mobs.advice speed`. These display help without executing the action.

## Target

Global game simulation.

## Steps

Run without arguments to read speed, or choose 0..12. Zero pauses and one resumes normally.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.speed
mobs.speed 0
mobs.speed 1
```

## Limits and expected results

Uses the native speed request. High speed may alter performance and make changes harder to observe. This does not advance an exact number of days.
