# mobs.usage

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Explain exact syntax, targeting, previews and click tools without running anything.

```text
mobs.usage <command>
```

## In-game advice

`mobs.advice.usage` or `mobs.advice usage`. These display help without executing the action.

## Target

Read-only discovery; no settlement required unless loaded game data is being requested.

## Steps

Supply a short command name to read its syntax and targeting summary. For a fuller guide, use mobs.advice.<command>.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.usage pile
mobs.usage spawn_deposit
```

## Limits and expected results

Required arguments use angle brackets; optional arguments use square brackets. Do not type either bracket.
