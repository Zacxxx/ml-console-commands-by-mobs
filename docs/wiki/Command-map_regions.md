# mobs.map_regions

Guide for **0.16.0-alpha.3**, game **0.8.117**.

List map region IDs including unclaimed/foreign regions for claim commands.

```text
mobs.map_regions
```

## In-game advice

`mobs.advice.map_regions` or `mobs.advice map_regions`. These display help without executing the action.

## Target

Loaded map.

## Steps

List all map region IDs, including unclaimed and foreign regions, for map/claim operations.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.map_regions
```

## Limits and expected results

Listing a region does not make it owned or allow ordinary resource edits there.
