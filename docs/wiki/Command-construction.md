# mobs.construction

Guide for **0.16.1-alpha.5**, game **0.8.117**.

Pause or resume unfinished construction across the target region.

```text
mobs.construction <pause|resume>
```

## In-game advice

`mobs.advice.construction` or `mobs.advice construction`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Use pause or resume to change unfinished sites throughout the target region.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.construction pause
mobs.construction resume
```

## Limits and expected results

This affects the sites construction state, not the global simulation speed. It does not fill materials or finish work.
