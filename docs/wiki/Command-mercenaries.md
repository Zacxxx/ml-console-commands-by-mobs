# mobs.mercenaries

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Reroll mercenary offers through the native game function; does not hire any units.

```text
mobs.mercenaries reroll
```

## In-game advice

`mobs.advice.mercenaries` or `mobs.advice mercenaries`. These display help without executing the action.

## Target

Your player lord.

## Steps

Use the literal reroll subcommand, then reopen the hiring panel.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.mercenaries reroll
```

## Limits and expected results

Changes offers through the game; does not hire or pay units. No undo.
