# mobs.raiders

Guide for **0.15.0-alpha.1**, game **0.8.117**.

Click a playable region to request native hostile raider squads; maximum six, supports preview.

```text
mobs.raiders [1..6] [preview]
```

## In-game advice

`mobs.advice.raiders` or `mobs.advice raiders`. These display help without executing the action.

## Target

A playable clicked region; this tool can create hostile squads.

## Steps

Choose 1..6 squads, preview, close the console and click the region.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.raiders 1 preview
```

## Limits and expected results

Creates hostile raiders rather than recruiting your militia. No undo.
