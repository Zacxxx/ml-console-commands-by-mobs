# mobs.perk_remove

Guide for **0.16.1-alpha.5**, game **0.8.117**.

Remove one extra card and rebuild active effects; preserves primary cards and effects supplied by other cards.

```text
mobs.perk_remove <number|name> [preview]
```

## In-game advice

`mobs.advice.perk_remove` or `mobs.advice perk_remove`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Remove an extra card by its listed number or unique key. Preview checks the plan before rebuilding effects.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.perk_remove BambergSmallholders preview
mobs.perks remove BambergSmallholders
```

## Limits and expected results

Preserves primary cards and effects supplied by other active cards. This is the companion reversal for an added extra; respec handles primary choices.
