# mobs.pond

Guide for **0.15.0-alpha.1**, game **0.8.117**.

Start the native Fishing Pond placement tool or click to remove an owned pond; supports preview.

```text
mobs.pond <place|remove> [preview]
```

## In-game advice

`mobs.advice.pond` or `mobs.advice pond`. These display help without executing the action.

## Target

Run the command, close the console, then click the intended location in an owned region. It is a one-shot tool with a five-minute expiry. mobs.cancel disarms it. Preview also requires the click, but changes nothing.

## Steps

place starts the native Fishing Pond building tool. Close the console and place it. Let construction finish. remove arms an owned pond-removal click, with preview support.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.pond place
mobs.pond remove preview
```

## Limits and expected results

A pond is a building, not a fish shoal. Creating one does not automatically prove fish are present. Use pond_fish on a completed pond. Removal has no undo.
