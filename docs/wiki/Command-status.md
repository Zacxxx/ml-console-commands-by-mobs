# mobs.status

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Show your lord's balances and the command target region's wealth.

```text
mobs.status
```

## In-game advice

`mobs.advice.status` or `mobs.advice status`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Run without arguments to see treasury, influence and the chosen owned region with its wealth and approval.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.status
```

## Limits and expected results

If no owned region can be resolved, choose one using mobs.regions and mobs.region.
