# mobs.perk_clear

Guide for **0.16.1-alpha.5**, game **0.8.117**.

Remove all extra cards in the target region, keeping normal primary cards.

```text
mobs.perk_clear [preview]
```

## In-game advice

`mobs.advice.perk_clear` or `mobs.advice perk_clear`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Preview, then clear extra regional cards while keeping normal primary choices.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.perk_clear preview
mobs.perks clear
```

## Limits and expected results

Includes all extras in this region only. Effects are rebuilt from the retained primaries; perks_clear is an alias.
