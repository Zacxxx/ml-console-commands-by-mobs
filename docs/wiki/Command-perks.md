# mobs.perks

Guide for **0.16.0-alpha.3**, game **0.8.117**.

List/search cards, or use mobs.perks add/remove <card> and mobs.perks clear; preview is supported for changes.

```text
mobs.perks [list|add|remove|clear|search]
```

## In-game advice

`mobs.advice.perks` or `mobs.advice perks`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Open Development once to load the card table, then list/search cards. Use the displayed number or a unique key with add/remove; clear removes extras.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.perks list
mobs.perks add BambergSmallholders preview
mobs.perks add BambergSmallholders
```

## Limits and expected results

Cards are regional Origins/Rural Foundations, not development-tree points. Extras include penalties; shared effects apply once. The vanilla screen shows primary cards only. Numbers refer to this listing, not item IDs.
