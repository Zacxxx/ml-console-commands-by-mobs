# mobs.cancel

Guide for **0.16.1-alpha.5**, game **0.8.117**.

Cancel pending supply/forestry tools or further tree-growth batches; completed changes remain.

```text
mobs.cancel
```

## In-game advice

`mobs.advice.cancel` or `mobs.advice cancel`. These display help without executing the action.

## Target

Any pending one-shot click tool or queued forestry batch.

## Steps

Run before switching click tools or when you no longer want to place/deliver anything.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.cancel
```

## Limits and expected results

Stops future clicks/batches only. Completed placements, deliveries and growth are retained. It is not undo.
