# mobs.stock

Guide for **0.16.1-alpha.5**, game **0.8.117**.

Show target region stock through the native stock query, including reserved goods; optional name or ID filter.

```text
mobs.stock [search]
```

## In-game advice

`mobs.advice.stock` or `mobs.advice stock`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Read the target region stock, optionally filtering by item name or ID.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.stock
mobs.stock planks
```

## Limits and expected results

The native regional stock query can include reserved goods. It differs from a selected building inventory. Read-only.
