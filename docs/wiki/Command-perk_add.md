# mobs.perk_add

Guide for **0.16.0-alpha.3**, game **0.8.117**.

Activate an additional tier 1/2 card without replacing primary cards; includes its penalties. Use mobs.perks list for numbers.

```text
mobs.perk_add <number|name> [preview]
```

## In-game advice

`mobs.advice.perk_add` or `mobs.advice perk_add`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

List cards, then add a listed number or unique key. Preview first. mobs.perks add is the friendlier equivalent.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.perks list
mobs.perk_add BambergSmallholders preview
mobs.perks add BambergSmallholders
```

## Limits and expected results

Keeps primary cards and applies an extra regional card including its penalties. Primary cards cannot be added twice. Preserve Native/State when upgrading. Full save/load behavior needs continued confirmation.
