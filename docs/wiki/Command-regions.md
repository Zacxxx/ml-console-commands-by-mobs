# mobs.regions

Guide for **0.16.1-alpha.5**, game **0.8.117**.

List your owned regions and their IDs for mobs.region.

```text
mobs.regions
```

## In-game advice

`mobs.advice.regions` or `mobs.advice regions`. These display help without executing the action.

## Target

Loaded settlement.

## Steps

List owned region IDs and names. Choose one for mobs.region and check the pin with mobs.status.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.regions
```

## Limits and expected results

Region IDs depend on the save; item IDs cannot be used as region IDs.
