# mobs.bandits

Guide for **0.16.0-alpha.3**, game **0.8.117**.

Ask the game to spawn a bandit camp at a valid random location; supports preview.

```text
mobs.bandits [preview]
```

## In-game advice

`mobs.advice.bandits` or `mobs.advice bandits`. These display help without executing the action.

## Target

Map-wide native bandit-camp placement rules.

## Steps

Preview, then request a camp at a valid random game-chosen location.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.bandits preview
mobs.bandits
```

## Limits and expected results

This asks the game to choose a valid site; it does not place a camp at your mouse click. No undo.
