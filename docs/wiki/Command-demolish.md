# mobs.demolish

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Demolish selected owned buildings through the game with normal refund rules; preflight all targets and support preview.

```text
mobs.demolish selected [preview]
```

## In-game advice

`mobs.advice.demolish` or `mobs.advice demolish`. These display help without executing the action.

## Target

Select the owned building in the normal game view BEFORE opening the console. A pinned region does not select buildings. Up to 32 buildings only where the command explicitly allows a batch.

## Steps

Select owned buildings, preview the targets, then run without preview to request the native demolition with normal refunds.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.demolish selected preview
mobs.demolish selected
```

## Limits and expected results

Maximum 32 targets. All must be eligible before the first demolition. No undo; already completed demolitions remain if a later target changes.
