# mobs.skip_mourning

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Clear active mourning timers on owned buildings in the target region; preview lists the affected count.

```text
mobs.skip_mourning [preview]
```

## In-game advice

`mobs.advice.skip_mourning` or `mobs.advice skip_mourning`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Preview buildings with active mourning timers, then run normally to clear them.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.skip_mourning preview
mobs.skip_mourning
```

## Limits and expected results

This clears timers in the target region. It does not revive deceased residents or add a family. No undo.
