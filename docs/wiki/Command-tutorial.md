# mobs.tutorial

Guide for **0.16.0-alpha.3**, game **0.8.117**.

Read the tutorial chapter index, a numbered/named chapter, or the complete tutorial with all.

```text
mobs.tutorial [chapter|all]
```

## In-game advice

`mobs.advice.tutorial` or `mobs.advice tutorial`. These display help without executing the action.

## Target

Read-only discovery; no settlement required unless loaded game data is being requested.

## Steps

Read the chapter list, choose a chapter number/name, or print the full tutorial. Examples are explanatory text, never replayed automatically.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.tutorial
mobs.tutorial all
mobs.tutorial resources
```

## Limits and expected results

The full tutorial is long; use the numbered chapters or the linked GitHub wiki when console history is hard to read.
