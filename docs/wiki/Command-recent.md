# mobs.recent

Guide for **0.15.0-alpha.1**, game **0.8.117**.

List recent successful Mobs commands without replaying them; keeps 30, cleared on mod reload.

```text
mobs.recent [1..30]
```

## In-game advice

`mobs.advice.recent` or `mobs.advice recent`. These display help without executing the action.

## Target

Read-only discovery; no settlement required unless loaded game data is being requested.

## Steps

Show the most recent successful command strings without replaying them. Choose 1 to 30 entries.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.recent
mobs.recent 30
```

## Limits and expected results

History clears on mod reload. An armed click command being listed does not prove that its later placement succeeded.
