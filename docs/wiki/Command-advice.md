# mobs.advice

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Read a detailed command guide with targeting, explanations, examples and limits; dotted advice shortcuts also work.

```text
mobs.advice [command]
```

## In-game advice

`mobs.advice.advice` or `mobs.advice advice`. These display help without executing the action.

## Target

Read-only discovery; no settlement required unless loaded game data is being requested.

## Steps

Use the dotted shortcut or give a command name after mobs.advice. Both display the same detailed guide without executing the command.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.advice.pile
mobs.advice spawn_resource
mobs.advice.soil
```

## Limits and expected results

Each guide includes targeting, steps, examples, limits and related tools. Advice works at the main menu.
