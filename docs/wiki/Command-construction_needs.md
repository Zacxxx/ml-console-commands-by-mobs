# mobs.construction_needs

Guide for **0.15.0-alpha.1**, game **0.8.117**.

Report selected construction materials, or region totals; missing counts include incoming deliveries.

```text
mobs.construction_needs [region]
```

## In-game advice

`mobs.advice.construction_needs` or `mobs.advice construction_needs`. These display help without executing the action.

## Target

Select the owned building in the normal game view BEFORE opening the console. A pinned region does not select buildings. Up to 32 buildings only where the command explicitly allows a batch.

## Steps

Select one construction site for a detailed bill, or request region totals without a building selection.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.construction_needs
mobs.construction_needs region
```

## Limits and expected results

Required, stored and incoming goods are counted separately. Missing amounts include incoming deliveries to avoid oversupply. Read-only.
