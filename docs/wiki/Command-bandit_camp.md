# mobs.bandit_camp

Guide for **0.15.0-alpha.1**, game **0.8.117**.

Click clear unclaimed ground to register a native hostile camp squad and camp-building order; resume simulation afterward; no undo.

```text
mobs.bandit_camp [preview]
```

## In-game advice

`mobs.advice.bandit_camp` or `mobs.advice bandit_camp`. These display help without executing the action.

## Target

Clear UNCLAIMED ground, away from building borders.

## Steps

Run with preview, close the console and click clear unclaimed ground. Repeat without preview to request a real camp squad/order, then resume simulation.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.bandit_camp preview
mobs.bandit_camp
```

## Limits and expected results

Owned or foreign-claimed ground is rejected. This is hostile content, not your own settlement troops. No undo.
