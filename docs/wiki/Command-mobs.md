# mobs

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Quick-start dashboard or run an exact command using spaces; misspellings only suggest, never execute.

```text
mobs [command words...]
```

## In-game advice

`mobs.advice.mobs` or `mobs.advice mobs`. These display help without executing the action.

## Target

Read-only discovery; no settlement required unless loaded game data is being requested.

## Steps

Open the console and browse the dashboard or searchable help. Copy exact command syntax; replace placeholders and omit brackets.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text

```

## Limits and expected results

help is an alias for mobs.help. mobs uses exact command matching when dispatching actions; typo matches only suggest.
