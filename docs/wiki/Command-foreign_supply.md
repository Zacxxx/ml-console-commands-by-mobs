# mobs.foreign_supply

Guide for **0.15.0-alpha.1**, game **0.8.117**.

Print the global foreign market supply, optionally filtered by item name or ID; changes nothing.

```text
mobs.foreign_supply [search]
```

## In-game advice

`mobs.advice.foreign_supply` or `mobs.advice foreign_supply`. These display help without executing the action.

## Target

Loaded global foreign-market supply.

## Steps

Read all entries or filter by display name/item ID.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.foreign_supply
mobs.foreign_supply iron
```

## Limits and expected results

Read-only global market information; not stock in your target region and not a delivery.
