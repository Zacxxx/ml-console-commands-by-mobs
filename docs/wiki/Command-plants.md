# mobs.plants

Guide for **0.16.1-alpha.5**, game **0.8.117**.

Inspect selected buildings planted crops: type, position, growth, yield and soil-cell index; read only, first 100 plants.

```text
mobs.plants
```

## In-game advice

`mobs.advice.plants` or `mobs.advice plants`. These display help without executing the action.

## Target

Select the owned building in the normal game view BEFORE opening the console. A pinned region does not select buildings. Up to 32 buildings only where the command explicitly allows a batch.

## Steps

Select planted fields or a forestry building, then inspect plant records.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.plants
```

## Limits and expected results

Read-only: prints counts and up to 100 records with type, position, growth, yield and soil-cell index. It does not plant, harvest or change fertility.
