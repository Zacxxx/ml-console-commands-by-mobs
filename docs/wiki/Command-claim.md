# mobs.claim

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Start a claim without influence cost, or finish your existing claim(s); explicit map selection/ID, supports preview.

```text
mobs.claim <start|finish> [region-id|all] [preview]
```

## In-game advice

`mobs.advice.claim` or `mobs.advice claim`. These display help without executing the action.

## Target

Explicit map selection or a real region ID from mobs.map_regions.

## Steps

Start a claim without influence cost, or finish a claim already belonging to your lord. Preview before applying; all is supported for existing claims when appropriate.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.claim start preview
mobs.claim finish all preview
```

## Limits and expected results

Not the same as choosing the command-target region. Finish requires a valid existing claim; it does not simply grant arbitrary foreign land. No undo.
