# mobs.livestock_cooldown

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Read or clear the target region's next livestock order cooldown; does not spawn or deliver animals.

```text
mobs.livestock_cooldown [reset]
```

## In-game advice

`mobs.advice.livestock_cooldown` or `mobs.advice livestock_cooldown`. These display help without executing the action.

## Target

Your owned command-target region. Run mobs.regions, then mobs.region with a listed ID; confirm mobs.status. mobs.region auto clears the pin.

## Steps

Run without arguments to inspect the next livestock-order cooldown; reset clears that cooldown.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.livestock_cooldown
mobs.livestock_cooldown reset
```

## Limits and expected results

Does not order, spawn or deliver animals, and does not fill a trading post inventory.
