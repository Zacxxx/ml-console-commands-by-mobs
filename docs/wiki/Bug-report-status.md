## Useful retest sequence

Use a separate test save and the **same mod version reported by mobs.version**. Select an owned storehouse before opening the console, then try `mobs.give 17 20 preview`. Select a planted field and try `mobs.soil restore all selected preview`. For new deposits, preview a placement, then create on clear owned ground and inspect both the world decal and the finite surface amount before/after save/load.

To remove an old stripe, preview `mobs.remove_deposit iron`, then apply at the old reserve. If its decal was already deleted and only an empty mineral marker remains, preview `mobs.resource remove iron`. These operations are separate from deleting real surface clumps. Never assume `all` means every deposit globally: it accepts the nearest matching kind for that click.

[Open a reproducible issue](https://github.com/Zacxxx/ml-console-commands-by-mobs/issues) with game/loader/mod versions, exact command, owned target, result text, month/season where relevant, and sanitized log excerpts. Do not include private paths or complete saves unless you choose to share them.
