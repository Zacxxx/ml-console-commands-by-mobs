# mobs.skip_day

Guide for **0.16.0-alpha.3**, game **0.8.117**.

Advance days through the native date update rather than overwrite the calendar; maximum 30, preview available.

```text
mobs.skip_day [1..30] [preview]
```

## In-game advice

`mobs.advice.skip_day` or `mobs.advice skip_day`. These display help without executing the action.

## Target

Global game calendar.

## Steps

Preview a count from 1..30, then request native day updates if intended.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.skip_day 1 preview
mobs.skip_day 1
```

## Limits and expected results

Daily simulation events may run. It is not a guarantee that workers finish travel/jobs or that population appears. No undo.
