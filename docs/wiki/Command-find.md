# mobs.find

Guide for **0.16.1-alpha.6**, game **0.8.117**.

Ranked multiword and typo-tolerant command search; read only.

```text
mobs.find <words...>
```

## In-game advice

`mobs.advice.find` or `mobs.advice find`. These display help without executing the action.

## Target

Read-only discovery; no settlement required unless loaded game data is being requested.

## Steps

Type several ordinary words or a misspelled command name. Read the ranked suggestions, then enter the exact desired command.

## Examples

Examples below are command text to enter yourself; reading this page never runs them.

```text
mobs.find finish buildings
mobs.find fish
mobs.find fertility
```

## Limits and expected results

Search never executes guessed commands. Use advice on a suggested command to learn its full workflow.
